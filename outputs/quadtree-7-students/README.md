# Student workbook setup

Upload `quadtree-student-shared.xlsx` to OneDrive or SharePoint and share an editing link with the seven students. Everyone should edit the same copy. Put that link in Canvas or provide it in class.

The workbook contains the 16 x 16 starter grid, two prefilled examples, a live black-and-white preview, the seven student assignments, and the sixteen encoded block descriptions. It contains no instructor answer sheet or completed image.

Use `Pixel Grid!A1:P20` to export PBM text. The included `.pbm` file is the starter state, not the finished picture.

Full activity instructions: [Quadtree decoding](../../qdt/challenge_qdt.md).
